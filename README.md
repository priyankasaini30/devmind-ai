# DevMind

### AI-Powered Developer Productivity Platform

DevMind is a full-stack platform designed to help developers with coding, interview preparation, technical knowledge, and personal development history in one place.

## Features

- 🤖 AI-powered Code Review
- 💻 Coding Assistance
- 🎯 Interview Preparation
- 📝 Technical Notes
- 📚 Learning & Knowledge Management
- 📊 Review and Activity History
- 🔐 User Authentication

## Tech Stack

### Frontend
- React
- Vite
- JavaScript
- Tailwind CSS

### Backend
- Node.js
- Express.js

### Database
- MongoDB

### AI
- Google Gemini API
